# 🌸 제주 전농로 벚꽃거리 환경철학 수업 웹 애플리케이션

> **"나무를 위해 조금 불편해도 괜찮을까?"**  
> 환경교육사 실기 연계 중등 환경철학(인간중심주의 vs 생태중심주의 vs 공존) 참여형 인터랙티브 수업 도구

---

## 📌 프로젝트 소개
본 프로젝트는 제주 전농로 벚꽃길 보존 및 도로 확장 딜레마를 중심으로, 중학생들이 일상에서 체감할 수 있는 환경·생태 가치관을 탐색하고 토론할 수 있도록 제작된 단일 페이지 웹 애플리케이션(SPA)입니다.

별도의 복잡한 백엔드 서버 설치 없이 브라우저 자체 기능(`BroadcastChannel` & `localStorage`) 및 Firebase Realtime Database(선택)를 통해 학급 내 실시간 상호작용을 지원합니다.

---

## 🧭 수업 단계별 주요 기능

### 1단계: 활동 1 · 환경·생태 딜레마 10선 (밸런스 게임)
- 실제 국내 10가지 환경·생태 갈등 사례(가로수 가지치기, 국립공원 케이블카, 신재생에너지 산림 훼손 등) 탐색
- 편향을 방지하는 질문 중심의 직관적 선택지 UI
- 5가지 가치관 성향 분석 프로필 및 학급 전체 성향 통계 시각화

### 2단계: 활동 2 · 나의 선택은? (실시간 투표)
- 전농로 벚꽃길 도로 확장 vs 나무 보존 vs 제3의 공존 방안 실시간 투표
- 실시간 막대 그래프 및 도넛 차트 시각화
- 내 선택의 이유 작성 및 학급 의견 실시간 공유

### 3단계: 활동 3 · 공존 방안 디지털 협업 보드
- 모둠별/개인별 공존 아이디어 실시간 포스트잇 부착
- 색상 선택, 모둠별 필터링, 공감/좋아요(❤️) 기능

### 4단계: 정리 · 나만의 환경 가치 선언문 생성
- 수업 내용을 바탕으로 빈칸을 채워 완성하는 가치 선언문
- 고화질 카드뉴스 이미지(PNG) 및 PDF 다운로드 기능 지원

---

## 🛠️ 기술 스택
- **Frontend:** HTML5, CSS3, Modern JavaScript (Vanilla ES6+)
- **Charts:** Chart.js
- **Export:** html2canvas, jsPDF
- **Realtime Sync:** BroadcastChannel API, LocalStorage Event, Firebase Realtime Database (옵션)
- **UI/UX:** 반응형 디자인 (PC 2×2 / 일자 배열 전환 지원, 태블릿, 모바일 완벽 지원)

---

## 🚀 실행 방법
별도의 설치 과정 없이 `index.html` 파일을 웹 브라우저(Chrome, Edge, Safari 등)에서 더블 클릭하여 바로 실행할 수 있습니다.
- 교사 모드: 우측 상단 `[👩‍🏫 교사]` 버튼을 눌러 비밀번호(`1234`)를 입력하면 방 코드 설정 및 초기화 제어가 가능합니다.
